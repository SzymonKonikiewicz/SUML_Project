# 📊 SUML_Project

This is a basic cloud application which implements a machine learning model to predict the price of a flat in New York City.

## 🛠 Technologies Used
* **Languages:** Python 3.13
* **Tools & Frameworks:** Docker, Terraform

## ⚙️ Environment Setup

**Prerequisites:** Python 3.13.13

It is recommended to use Conda to manage the environment. 

# Create and activate the environment
conda create -n suml_project python=3.13
conda activate suml_project

# Install dependencies
python -m pip install -r requirements.txt
